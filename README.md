# Networkwalks — Cybersecurity Lab

**A practical cybersecurity learning environment built with Oracle VirtualBox.**

## Overview

Networkwalks is an ongoing hands-on cybersecurity lab focused on understanding virtual networking, Linux environments, network security and practical security testing.

The project documents my journey through configuring virtual machines, establishing network connectivity, troubleshooting infrastructure and conducting controlled security exercises.

Rather than focusing solely on tools, this lab emphasizes understanding the underlying technologies and documenting practical results.

## Lab Environment

| Component | Details |
|---|---|
| Hypervisor | Oracle VirtualBox |
| Virtual Network | NAT / NAT Network |
| DHCP | Enabled on configured NAT Network |
| Virtual Machines | Multiple VMs |
| Host Platform | To be documented |
